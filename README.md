#  The AVSpeechSynthesizer turns syllables into words.

I was writing an application that uses the AVSpeechSynthesizer and stumbled across this error by chance.

Some syllables produce complete words, even though only the syllable should be spoken.
I posted the problem in the Apple forum, but received no answer, just like with other bugs.
I received an answer regarding the file deletion issue and the error with the recycle bin, although it was not satisfactory.

[Apple Forum](https://developer.apple.com/forums/thread/805542)
